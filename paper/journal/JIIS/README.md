# JIIS preparation

The active target is **Journal of Intelligent Information Systems**, followed by
KAIS and IJMLC. The canonical [JIIS brief and readiness backlog](../../../wiki/manuscript/JIIS-Journal.md)
owns the title, section plan, source map and scientific work needed before submission.
The [venue register](../../../wiki/manuscript/journal-targets.toml) owns verified
publisher requirements; change the wiki before adapting the manuscript.

This is a preparation area. No JIIS manuscript, compiled PDF or submission-ready
package has been produced yet. The earlier [DYU package](../DYU/README.md) remains
available for editorial reference. Its historical numerical tables are not
automatically eligible for the JIIS paper.

At package assembly, the checked JIIS instructions require:

- LaTeX sources, styles, figures and a compiled PDF, with a flat upload layout.
- At most 25 pages including references, tables and figures.
- An abstract of 150–250 words and 4–6 keywords.
- Numeric reference citations, accurate declarations and data availability.
- Resolution of the guideline's Springer Nature template / `smallcondensed`
  ambiguity before fixing layout.

Source: [JIIS submission guidelines](https://link.springer.com/journal/10844/submission-guidelines),
checked 2026-10-02. Recheck at submission. Compile and render substantial
document jobs through Slurm, as required by the project workflow.

Final scientific admission uses the existing [Paper Export Contract](../../../wiki/manuscript/Paper-Export-Contract.md).
The active paper pointer is still `UNRELEASED`; no journal submission is implied.
