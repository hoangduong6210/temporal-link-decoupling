# DYU journal working package

The canonical editable manuscript is Latex_full/main.tex. It contains the complete bibliography and vector diagram and can compile independently of the research repository.

- Latex_full/: LaTeX, PDF, numerical checks, reference audit and export scripts.
- DYU_Overleaf.zip: uploadable source package; select XeLaTeX and main.tex in Overleaf.
- Word/DYU_Journal_Manuscript.docx: modern editable Word version, including Office Math equations.
- Word/DYU_Journal_Manuscript.doc: legacy Word 97–2003 export for journal submission.
- Word/template.docx: retained conversion of the supplied instructional template, used by the Word exporter.
- EDITORIAL_AUDIT_VI.txt: editorial, citation and evidence review, with limitations.

The PDF and Word exports contain the same manuscript and result values. Pagination may differ between renderers and fonts. These files are working submission materials; no submission or formal evidence-snapshot admission is implied.
