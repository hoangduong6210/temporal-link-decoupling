# Evidence-admitted paper snapshots

No evidence-admitted paper snapshot is present. `paper/CURRENT` is
`UNRELEASED`; the sole preserved conference manuscript lives at
`paper/conference/` and is deliberately outside this namespace.

A future snapshot must be generated from the canonical wiki and current frozen
evidence. It must include `snapshot.toml`, `results.lock.yaml`,
`numeric-provenance.jsonl`, `checksums.sha256`, all declared source files, and
every rendered export. Every scientific number must resolve to a claim,
evidence record, execution job, checksum, and artifact selector.
