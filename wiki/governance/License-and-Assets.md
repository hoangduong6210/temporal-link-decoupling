# License and Assets

No project code license was present in the migration source, so this repository
does not imply a public code grant. A public source release remains owner-gated;
internal version control and evidence capture do not change that boundary.

Dataset acquisition is closed under a conservative fetch-only policy recorded
in `resources/source_registry.json`. The registry pins the public upstream page,
exact raw URLs and digests, retrieval metadata, citation notice, builders, and
processed identities. No explicit upstream dataset license grant was identified,
therefore raw or processed dataset bytes must not be redistributed by this
project. A future redistribution decision requires a reviewed rights record and
a new registry identity.

`IEEEtran.cls` retains its own LPPL notice and is not relicensed by this project.
