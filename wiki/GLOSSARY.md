# Glossary

| Term | Controlled meaning |
|---|---|
| Decoupled | Link-prediction loss does not update the temporal backbone. |
| Coupled | Link-prediction loss has a gradient path into the backbone. |
| Freeze-then-probe | End-to-end pretraining followed by frozen-backbone head fitting. |
| Inductive edge | Test edge containing a node outside the train/validation seen set. |
| ID-fixed | Bipartite user and item IDs occupy disjoint node namespaces. |
| Legacy import | Preserved artifact that is neither frozen nor claim-admitted. |

## Recovery terminology

**Recovered:** original artifact bytes are available again and have a recorded preservation hash. **Arithmetically reconciled:** a specified aggregate is reconstructed from its retained rows. **Admitted:** source, data, protocol, execution and release bindings meet the scientific contract. Neither recovery nor arithmetic alone implies admission. **Legacy proxy:** a local approximation of a published architecture, unsuitable for a faithful external-baseline claim.
